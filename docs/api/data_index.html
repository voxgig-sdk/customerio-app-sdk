Fields

Field Type Required Description

create

POST /v1/data_index/attributes

Operation ID: updateAttributeMetadata.

Authentication: bearer token (Bearer-Auth).

Request body

application/json

Property Type Required Description
attributes array of object Yes Array of attribute updates
attributes[].description string No The purpose of the attribute. This helps our AI tools understand your data.
attributes[].name string Yes The name of the attribute to update
attributes[].privacy_level enum: 0, 1 No Available on Premium plans. This indicates whether an attribute is sensitive or not. 0 means NOT sensitive. 1 means sensitive.

Responses

204: Attributes updated successfully
400: Invalid request format

application/json

Property Type Required Description
errors array of object No
errors[].detail enum: Invalid request format No The reason for failure.
errors[].status enum: 400 No The response code.
422: Validation error

application/json

Property Type Required Description
errors array of object No
errors[].detail enum: Empty attributes array, Too many attributes, Privacy level feature not enabled No The reason for the response.
errors[].source object No
errors[].source.pointer string No The path to the attribute that caused the error. 0 is the first attribute, 1 is the second, and so on.
errors[].status enum: 422 No The response code.
500: Internal server error

POST /v1/data_index/events

Operation ID: updateEventMetadata.

Authentication: bearer token (Bearer-Auth).

Request body

application/json

Property Type Required Description
events array of object Yes Array of event updates
events[].description string No The meaning of the event
events[].name string Yes The name of the event

400: Invalid request format

application/json

Property Type Required Description
errors array of object No

errors[].status enum: 400 No The response code.
422: Validation error

application/json

Property Type Required Description
errors array of object No

errors[].source object No
errors[].source.pointer string No The path to the event that caused the error.
errors[].status enum: 422 No
