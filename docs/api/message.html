GET /v1/messages

Operation ID: listMessages.

Authentication: bearer token (Bearer-Auth).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | start | query | string | No | The token for the page of results you want to return. Responses contain a next property. Use this property as the start value to return the next page of results. | | limit | query | integer | No | The maximum number of results you want to retrieve per page. | | type | query | enum: email, webhook, twilio, whatsapp, slack, push, ... | No | The type of item you want to return metrics for. When empty, the response contains metrics for all possible types. | | metric | query | enum: attempted, sent, delivered, opened, clicked, converted, ... | No | Determines the metric(s) you want to return. | | drafts | query | boolean | No | If true, your request returns drafts rather than active/sent messages. | | campaign_id | query | integer | No | The automation you want to filter for. | | newsletter_id | query | integer | No | The one-time send you want to filter for. | | action_id | query | integer | No | The action you want to filter for. | | start_ts | query | integer (unix timestamp) | No | The beginning timestamp for your query. | | end_ts | query | integer (unix timestamp) | No | The ending timestamp for your query. | | get_tracked_responses | query | boolean | No | If true, the response includes tracked_responses for each message, an object containing tracked response option names for in-app survey responses. |
