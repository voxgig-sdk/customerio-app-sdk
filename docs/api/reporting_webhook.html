Operations

Every route this entity exposes. Each route links to its own reference on this page.

Method Route SDK operation Returns
POST /v1/reporting_webhooks create Returns your webhook configuration and the ID of the webhook
GET /v1/reporting_webhooks list Returns an array of your reporting_webhooks
GET /v1/reporting_webhooks/{webhook_id} load Returns an individual webhook configuration
DELETE /v1/reporting_webhooks/{webhook_id} remove A successful request has no response
PUT /v1/reporting_webhooks/{webhook_id} update Returns your webhook configuration and the ID of the webhook

Fields

Field Type Required Description
disabled boolean No Set to true to quit sending events to the webhook URL.
endpoint string Yes The webhook URL.
events array Yes Specifies the types of events you want to report to your webhook.
full_resolution boolean No Set to false to send unique open and click events to the webhook.
id integer No The identifier for the webhook.
name string Yes The name of your webhook.
type string No The type of webhook, webhook for a standard reporting webhook or js for a JavaScript webhook.
with_content boolean No Set to true to include the message body in _sent events.

create

POST /v1/reporting_webhooks

Operation ID: createWebhook.

Authentication: bearer token (Bearer-Auth).

Request body

application/json

Property Type Required Description
disabled boolean No Set to true to quit sending events to the webhook URL. Set to false to enable the webhook.
endpoint string (url) Yes The webhook URL.
events array of enum: customer_subscribed, customer_unsubscribed, customer_subscription_preferences_changed, email_drafted, email_attempted, email_sent, ... Yes Specifies the types of events you want to report to your webhook. See our reporting webhooks reference for more information about event types and the information they return.
full_resolution boolean No Set to false to send unique open and click events to the webhook. Set to true to send all events.
id integer No The identifier for the webhook.
name string Yes The name of your webhook.
type enum: webhook, js No The type of webhook, webhook for a standard reporting webhook or js for a JavaScript webhook.
with_content boolean No Set to true to include the message body in _sent events.
