Operations

Every route this entity exposes. Each route links to its own reference on this page.

Method Route SDK operation Returns
GET /v1/campaigns/{campaign_id}/messages list Returns an array of messages. Each object represents a different message in your automation
GET /v1/campaigns/{campaign_id}/actions/{action_id}/metrics/links list Returns action metrics by series (with increments are based on the period and step in your request) for the automation
GET /v1/campaigns/{campaign_id}/metrics/links list Returns an array of link objects. Each object represents a different link in your automation and contains independent metrics
GET /v1/campaigns/{campaign_id}/actions list Returns automation actions. Each object represents an individual action
GET /v1/campaigns list Returns an array of automation objects
GET /v1/campaigns/{campaign_id}/actions/{action_id}/metrics load Returns action metrics by series, where each increment is based on the res in your request. For a multi-language message, also returns a per-variant breakdown in language_variants
GET /v1/campaigns/{campaign_id}/metrics load Returns automation metrics by series based on the parameters of the request
GET /v1/campaigns/{campaign_id}/journey_metrics load Each journey_metric item in the response is an array. Each item in a metric array represents the number of journeys that started within the time increment ("resolution", day or month) and eventually achieved that metric
GET /v1/campaigns/{campaign_id}/actions/{action_id}/language/{language} load Returns information for the requested automation action language variant
GET /v1/campaigns/{campaign_id}/actions/{action_id} load Returns the requested automation action
GET /v1/campaigns/{campaign_id} load Returns metadata for the automation
PUT /v1/campaigns/{campaign_id}/actions/{action_id}/language/{language} update Returns the updated automation action
PUT /v1/campaigns/{campaign_id}/actions/{action_id} update Returns the updated automation action
