GET /v1/optouts

Operation ID: getOptouts.

Authentication: bearer token (Bearer-Auth).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | from | query | string | No | Filter for a specific sender on any channel. For SMS, this is a sender phone number (E.164), an alphanumeric sender ID, or a messaging-service SID; for WhatsApp, it's the sender phone number. | | start | query | string | No | A pagination cursor, a base64-encoded value returned in the next property of the previous page. Omit this parameter to return the first page; pass the previous page's next value to return the following page. | | limit | query | integer | No | The maximum number of results you want to retrieve per page. |

optouts[].optouts[].channel enum: sms, whatsapp No The channel that the person is opted out of.
optouts[].optouts[].from string No The sender that the person is opted out of. For SMS, this is a sender phone number (E.164), an alphanumeric sender ID, or a messaging-service SID; for WhatsApp, it's the sender phone number.

Request body

application/json

Property Type Required Description
optouts array of object Yes The senders and channels you want to opt the person out of, or back in to. Provide one entry per sender/channel.
optouts[].channel enum: sms, whatsapp No The channel for the opt-out. Defaults to sms.
optouts[].from string Yes The sender you want to opt the person out of, or back in to. For SMS, this is a sender phone number (E.164), an alphanumeric sender ID, or a messaging-service SID; for WhatsApp, it's the sender phone number.
optouts[].optout boolean Yes Set to true to opt the person out of the sender, or false to opt them back in.

Example request body:

    {
      "channel": "sms",
      "from": "+15551234567",
      "optout": true
    }
  ]
}
