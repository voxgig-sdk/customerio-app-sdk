Configuration

Set the server URL and credentials for your environment. Enable only the features your application needs.

Features

  • Request/response capture ring buffer for debugging
  • Idempotency keys for safe retries of mutating operations
  • Statistics capture: per-operation counters and latency
  • Pagination signals for list operations
  • Client-side rate limiting via a token bucket
  • Automatic retry of transient failures with exponential backoff
  • In-memory mock transport for testing without a live server
  • Per-request timeout with transport abort

customerio-app_list

List records for an entity.

{
  "type": "object",
  "required": [
    "entity"
  ],
  "properties": {
    "entity": {
      "type": "string",
      "description": "action | activity | asset | attribute | automation | broadcast | campaign | collection | content | customer | data_index | delivery | design_studio | design_studio_email | email | end | esp_suppression | export | import | in_app | inbox_message | info | ip_address | language | link | live_notification | message | newsletter | newsletter_metric | newsletter_variant | object | object_type | opt_out | push | relationship | reporting_webhook | search_suppression | segment | send_message | sender_identity | sms | snippet | start | subscription_center | subscription_channel | subscription_topic | suppression | test_group | transactional | trigger | update | whatsapp | workspace"
    },
    "query": {
      "type": "object",
      "description": "Optional match fields for the selected entity."
    }
  }
}

Supported entities: activity, asset, automation, broadcast, collection, customer, design_studio, design_studio_email, export, info, message, newsletter, newsletter_metric, newsletter_variant, object, opt_out, reporting_webhook, segment, sender_identity, snippet, subscription_center, transactional, workspace.
